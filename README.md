# Manual & Automation Testing of Login Page

This repository contains a **fresher-level QA project** demonstrating both **manual testing** and **basic automation testing** skills.

## 📌 Project Overview

* Application Under Test (AUT): [Practice Test Automation – Login Page](https://practicetestautomation.com/practice-test-login/)
* Objective: Validate login functionality using **manual test cases** and **Selenium automation scripts**.

## 📂 Deliverables

* **Project Overview Document** – Scope, objectives, approach
* **Test Artifacts (Excel)** – Test scenarios, test cases, bug reports, execution summary
* **Test Summary Report (Word)** – Final execution report with pass/fail status and logged defects
* **Automation Scripts (Python + Selenium)** – Valid and invalid login scenarios

## 🛠️ Tools & Skills Used

* Manual Testing (Test Cases, Bug Reporting, Test Summary)
* Selenium with Python (Basic Automation)
* MS Excel, Word
* SDLC/STLC, Bug Life Cycle

## ✅ Key Highlights

* Designed and executed **6 manual test cases** covering positive & negative login scenarios
* Logged **2 dummy bugs** and created a **Test Summary Report**
* Automated **2 test cases (valid & invalid login)** with Selenium + Python
